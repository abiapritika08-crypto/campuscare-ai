🎓 CampusCare AI — AI-Powered Student Success Platform

Helping faculty understand students, identify academic challenges, and support better student outcomes through data-driven insights.

🌐 Live Website: "CampusCare AI" (https://campuscare-ai-bice.vercel.app/)

📌 About the Project

CampusCare AI is an AI-powered student analytics and success platform designed to help educational institutions better understand student performance and progress.

The platform helps faculty explore student data, identify students who may need additional academic support, discover meaningful patterns, and make informed decisions to improve student outcomes.

Developed as a hackathon project, CampusCare AI demonstrates how technology and data-driven analysis can support more proactive, student-centred education.

🎯 Problem Statement

Educational institutions often face challenges in understanding individual student needs, identifying academic difficulties early, and providing timely support.

Traditional approaches may not make it easy to analyse multiple student performance indicators together.

CampusCare AI aims to address these challenges by bringing student analytics, performance insights, and support-oriented features into one accessible platform.

💡 Our Solution

CampusCare AI provides a centralised dashboard that helps faculty explore student performance information and identify areas where additional attention may be needed.

By presenting student data in an organised and accessible way, the platform aims to support early intervention, better academic guidance, and informed educational decisions.

✨ Key Features

- 📊 Student Analytics Dashboard — Presents an overview of student-related information and performance indicators.
- 🎯 At-Risk Student Identification — Helps identify students who may require additional academic attention based on available indicators.
- 📚 Student Performance Insights — Supports the analysis of marks, attendance, and assignment completion.
- 🔎 Student Explorer — Enables faculty to explore student information.
- 🧩 Student Segmentation — Organises student information into meaningful groups for analysis.
- 🤝 Intervention Support — Helps faculty consider appropriate academic support for students who may be struggling.
- 🚀 Placement Readiness — Provides a dedicated area for exploring student placement preparedness.
- 📑 Reports — Offers a section for presenting student-related findings and insights.

Feature availability and functionality may vary as the project continues to develop.

🛠️ Technology Stack

The project is designed around a web-based frontend and a student analytics backend.

- Frontend: React.js
- Build Tool: Vite
- Styling: CSS
- Backend / Analytics: Python
- Data Handling: CSV-based sample student data
- Testing: Python testing files for scoring and API functionality
- Deployment: Vercel for the live website
- Version Control: Git and GitHub

⚙️ How It Works

1. Student Data: The platform uses available student information, such as attendance, marks, and assignment completion.
2. Data Analysis: Analytics and scoring logic process the available indicators.
3. Risk Identification: Students who may need additional attention can be identified based on the implemented scoring approach.
4. Visualisation: The dashboard presents student information and insights in an accessible format.
5. Faculty Support: Faculty can use these insights to explore student needs and consider appropriate academic interventions.

The platform is intended to support faculty decisions, not replace professional judgement. Risk indicators should not be treated as definitive conclusions about a student.

💻 Running the Frontend Locally

Prerequisites

- Node.js and npm
- Git
- A code editor such as Visual Studio Code

Installation

1. Clone the repository

Replace the repository URL below with your actual GitHub repository URL.

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the frontend project directory

If your "package.json" is in the project root, stay in that directory. Otherwise, navigate to the folder containing the frontend's "package.json".

cd YOUR_PROJECT_FOLDER

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL shown in your terminal to access the website.
